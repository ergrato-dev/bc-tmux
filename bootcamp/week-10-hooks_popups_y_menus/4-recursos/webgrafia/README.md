# Webgrafía — Semana 10

| Recurso | Descripción |
|---------|-------------|
| [tmux(1) — página de manual](https://man.openbsd.org/tmux.1) | Para esta semana: HOOKS (`set-hook`, `show-hooks`, la lista de eventos), `display-popup`, `display-menu`, `command-prompt` (`%%`, `%1`), `confirm-before`, `run-shell` (`-b`, `-C`, `-d`) y `pipe-pane -o` |
| [tmux wiki — Getting Started](https://github.com/tmux/tmux/wiki/Getting-Started) | "The command prompt", "Using the mouse" (los menús de serie) y "Other features", que presenta los hooks |
| [tmux wiki — FAQ](https://github.com/tmux/tmux/wiki/FAQ) | Respuestas de los autores; útil cuando un comando lanzado desde un hook o un `run-shell` no hace lo que esperabas |
| [fzf — README](https://github.com/junegunn/fzf) | Instalación, sintaxis de búsqueda y opciones. Su modo `--popup` abre fzf en un popup de tmux, pero es de versiones recientes: la 0.44 de Ubuntu 24.04 no lo trae, así que esta semana el popup lo abres tú. Cancelar con `Esc` sale con 130 (`man fzf`, EXIT STATUS) |
