# Webgrafía — Semana 11

| [tmux(1) — página de manual](https://man.openbsd.org/tmux.1) | Para esta semana: `run-shell`, `show-options` (`-q`, `-v`), `set-option` (`-o`, `-a`), `set-environment -g` y la sección FORMATS, que explica `#(...)` |
