# Ebooks y documentación gratuita — Semana 08

| Título | Formato | Descripción | Enlace |
|--------|---------|-------------|--------|
| Terminal Colors (termstandard) | HTML | Modos de color (8, 16, 256 y 24 bits), cómo detecta un programa el truecolor (`COLORTERM` y consulta a la terminal) y qué emuladores lo soportan | https://github.com/termstandard/colors |
| Ghostty — Terminfo | HTML | Caso real de un TERM de fuera propio (`xterm-ghostty`): qué falla por SSH si el servidor no tiene la entrada y cómo copiarla con `infocmp -x ... \| ssh ... tic -x -` | https://ghostty.org/docs/help/terminfo |

La guía de Ghostty sirve para cualquier emulador con entrada terminfo propia
(kitty, WezTerm, foot): cambia el nombre y el procedimiento es el mismo.
