## Antes de empezar

1. [Preparar el entorno](../docs/setup-entorno.md) — Ubuntu 24.04 o macOS, tmux ≥ 3.4 y Docker.
2. `./scripts/verificar-semana.sh --doctor` desde la raíz del repo.
3. [Cómo funciona el autograding](../docs/autograding.md).
4. [El proyecto hilo conductor `tmux-kit`](../docs/proyecto-hilo-conductor.md).
